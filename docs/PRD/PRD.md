## 1. 项目概述

### 1.1 一句话定位

一款运行在 Roblox 上的 **3D 体素风宠物收集对战游戏**：玩家孵化、培养并指挥体素灵宠，在 **PvE 推图、Rogue 远征、PvP 竞技** 中战斗，依靠 **放置产出 + 轮回增量** 持续变强，最终目标是集齐所有灵宠及其变异形态。

### 1.2 为什么做这款游戏（核心卖点）

| # | 卖点 | 说明 |
|---|---|---|
| 1 | **宠物模拟器的收集爽感 + 有决策的自动战斗** | Roblox 头部宠物游戏（Pet Simulator 99、Adopt Me、Bubble Gum Simulator 系列）本质是"点击收集 + 数字膨胀"，几乎没有策略层。本作的战斗**全自动**，但胜负由"元素克制 + 技能触发 + 遗物构筑 + 局外养成"决定——**决策在战前，爽感在战中**，同时保留大数字与孵蛋的爽感。 |
| 2 | **Rogue 远征 = 无限重玩** | 随机地图、遗物构筑、深渊等级、每周种子挑战，每局都不同；失败也积累元进度（永久天赋），"死亡即成长"。 |
| 3 | **增量 / 放置承接碎片时间** | 营地生产、离线收益、轮回乘数——不在线也在变强，玩家有充分理由每天回来。 |
| 4 | **体素美术：辨识度高、产能友好** | 体素模型制作快、风格统一、天然低面数，适配移动端性能预算；"进化 = 方块体积与细节增长"，成长反馈极其直观。 |
| 5 | **多维收集** | 每只灵宠 × 4 种变异形态（普通 / 黄金 / 彩虹 / 暗物质）+ 皮肤 + 遗物图鉴 + 称号 + 成就，收集维度远超同类。 |

### 1.3 设计支柱（做决策时的判断依据）

| 支柱 | 含义 | 我们不做的反例 |
|---|---|---|
| **简单上手，越玩越深** | 3 分钟学会战斗，30 小时后仍有构筑可研究 | 开局就抛出 10 种货币 20 个系统 |
| **永远有"下一步"** | 任何时刻屏幕上都有 ≥ 2 个可达成的短期目标 | 打完主线不知道干什么 |
| **每局都不一样** | Rogue 随机 + 赛季轮换 + 周挑战 | 一成不变的刷图 |
| **数字要往上涨** | 战力、产量、轮回乘数持续膨胀，用 K / M / B / T 呈现 | 成长停滞、天花板可见 |
| **公平的竞技** | PvP 提供数值标准化模式；付费买时间与外观，不买胜利 | 纯氪金碾压 |

### 1.4 目标平台与受众

- **平台**：Roblox 全平台，移动端优先（触屏 UI、单手可操作战斗、30 分钟内的短会话）。
- **语言与市场**：**英文为主**（Roblox 核心用户在北美 / 欧洲 / 东南亚 / 巴西），首发本地化 EN / ES / PT-BR / 中文（繁简）。注意：Roblox 中国大陆版（罗布乐思）已于 2022 年停运，本项目不能以国内玩家为主要目标市场。
- **核心受众**：9–16 岁 Roblox 主力用户（宠物模拟器 / 动漫塔防受众）。
- **次级受众**：16–24 岁喜欢 Rogue 构筑、数值成长的玩家（Loomian Legacy、Anime Defenders 类受众）。

### 1.5 项目目标（上线后 90 天）

| 指标 | 目标 |

| 同时在线（CCU）稳定值 | 2,000+（保守）/ 10,000+（理想） |

## 2. 市场与竞品分析

### 2.1 赛道现状（2026）

- 宠物 / 收集赛道是 Roblox 长青品类：**Adopt Me!** 至今仍稳定在 30 万+ 同时在线，Pet Simulator 99 在 8 万左右且更新节奏已放缓——头部老化，存在新品窗口。
- 2025 年的 **Grow a Garden**（放置种植）与 **Steal a Brainrot**（峰值超 2,500 万同时在线，平台纪录）证明：**放置 / 增量 + 收集 + 社交炫耀** 的组合在 Roblox 上有极强的爆发力。
- **动漫塔防（Anime Defenders / Anime Vanguards）** 证明 Roblox 年轻用户完全能接受"单位收集 + 抽卡 + 数值养成 + 策略战斗"的复合系统。
- 缺口：**没有一款头部产品同时具备"宠物收集 + 有策略的战斗 + Rogue 重玩 + 增量"**。宠物模拟器没有战斗深度；Loomian Legacy 有深度但回合制节奏慢、无放置、更新慢。

### 2.2 竞品对照

| 产品 | 核心循环 | 战斗 | 重玩机制 | 增量/放置 | 对本作的启示 |
|---|---|---|---|---|---|
| Pet Simulator 99 | 孵蛋 → 宠物产币 → 解锁新区 → 更贵的蛋 | 无（点击 / 挂机） | 新区域、活动 | 强（大数字、Rebirth） | 学习其"大数字 + 黄金/彩虹变异 + 全服稀有公告" |
| Adopt Me! | 养宠 + 交易 + 角色扮演 | 无 | 交易经济、限时宠物 | 弱 | 交易与限时稀有是超强社交驱动力（但客服/骗局成本高） |
| Grow a Garden | 种植 → 收获 → 卖 → 买更好种子 | 无 | 天气/变异随机 | 强（离线成长） | 离线成长 + 随机变异极易传播 |
| Anime Defenders | 抽单位 → 塔防关卡 → 升级 | 塔防 | 无尽模式、活动关 | 中 | 年轻用户接受抽卡+养成+策略 |
| Loomian Legacy | 捕捉 → 回合制对战 → 剧情 | 回合制（深） | PvP | 无 | 深度受众存在，但节奏和产能是短板 |
| **本作** | 孵化/捕捉 → 战斗（PvE/Rogue/PvP）→ 营地放置 → 轮回 | **全自动 1v1（后续 3→5 格）+ 元素克制 + 遗物构筑** | **Rogue 随机 + 赛季 + 周挑战** | **强** | 融合四类优势 |

### 2.3 差异化总结

> **"一款会打架的宠物模拟器，加上一个每天都不一样的 Rogue 地牢。"**

## 3. 核心玩法循环

### 3.1 循环示意

```
                  ┌──────────────────────────────────────────────┐
                  │                                              │
                  ▼                                              │
     ┌────────────────────┐    ┌────────────────────┐            │
     │ 获取灵宠            │    │ 培养灵宠            │            │
     │ 孵蛋 / 捕捉 / 融合   │───▶│ 升级·进化·星级·技能  │            │
     └────────────────────┘    └─────────┬──────────┘            │
                  ▲                       │                       │
                  │                       ▼                       │
     ┌────────────┴───────┐    ┌────────────────────┐   ┌────────┴─────────┐
     │ 资源产出            │    │ 战斗                │   │ 轮回（Prestige）   │
     │ 营地放置 / 离线收益  │◀───│ PvE 推图 / Rogue 远征│──▶│ 重置进度换永久乘数  │
     │ 战斗掉落            │    │ / PvP 竞技          │   │ 解锁新区域与新系统  │
     └────────────────────┘    └────────────────────┘   └──────────────────┘
                                          │
                                          ▼
                              ┌────────────────────┐
                              │ 收集与炫耀           │
                              │ 图鉴 · 变异 · 称号   │
                              │ 排行榜 · 展示柜      │
                              └────────────────────┘
```

### 3.2 分时段循环

| 时间尺度 | 玩家在做什么 | 驱动力 |
|---|---|---|
| **30 秒** | 一场自动战斗：战前看克制提示 → 开战 → 伤害数字跳出 → 结算（Rogue 中接三选一遗物） | 期待感、数字爽感、决策反馈 |
| **5 分钟** | 打 3–5 关 → 收金币 → 孵 1–3 颗蛋 → 升级宠物 → 推下一关 | 短期目标、开箱期待 |
| **30 分钟（一次会话）** | 一局 Rogue 远征（15–20 分钟）+ 收营地产出 + 做日常任务 + 竞技场 3 场 | 构筑乐趣、日常完成感 |
| **1 天** | 3 次会话左右；离线收益回收；日常任务清空；蛋池刷新 | 回流钩子 |
| **1 周** | 周挑战（固定种子）排行、周任务、赛季通行证进度、一次轮回 | 中期目标 |
| **1 赛季（6 周）** | 赛季限定灵宠 / 皮肤、排位结算、新区域或新玩法 | 长期收集与地位 |

### 3.3 首日玩家旅程（FTUE 节奏）

| 时间点 | 事件 | 解锁 |
|---|---|---|
| 0:00 | 选择初始灵宠（火 / 水 / 草 三选一，经典设计） | — |
| 1:30 | 第一场自动战斗（引导：战前面板看元素克制 → 开战 → 试用 2× 加速） | 基础战斗 |
| 4:00 | 第一颗蛋孵化（必出 1 只与初始灵宠不同元素的优秀品质，用于应对被克制的关卡） | 孵蛋 / 换宠 |
| 8:00 | 营地解锁：方块矿场，把闲置宠物放进去产金币 | 放置 |
| 12:00 | 第一区 Boss 战（1v1，3 阶段机制演出） | Boss 机制 |
| 15:00 | 解锁 **迷雾远征**（教学局：精简 1 层，保证能通） | Rogue |
| 25:00 | 首局远征结束，获得远征印记 → 元天赋树 | 元进度 |
| 40:00 | 第二区解锁 + 融合机（5 只同种 → 黄金形态） | 变异收集 |
| 首日晚些 | 竞技场（异步）、每日任务、赛季通行证 | PvP / 运营 |
| 第 2–3 天 | 首次 **轮回** | 增量核心 |
| 第 1 周 | 第 3–4 区、彩虹融合、深渊等级、周挑战 | 深度内容 |

## 4. 宠物系统

### 4.1 基础定义

| 维度 | 设计 |
|---|---|
| **元素** | 火 🔥 / 水 💧 / 草 🌿 / 光 ✨ / 暗 🌑 / 无属性 ⬜ 六类。火→草→水→火 三角克制；光⇄暗互克；无属性无克制关系（万金油，数值略低）。克制 ×1.5，被克 ×0.67。 |
| **职业** | 攻击（DPS）/ 坦克 / 辅助 / 控制 四种，决定基础属性分布与技能类型。 |
| **属性** | HP、攻击 ATK、防御 DEF、速度 SPD（影响攻击间隔与技能冷却）、暴击率 CRIT。 |
| **技能** | 每只灵宠：1 个主动技能（冷却 6–15 秒，**由 AI 按配表触发条件自动释放**，见 5.3）+ 1 个被动。进化到第 3 阶段解锁强化版主动技能。 |
| **稀有度** | 普通 → 优秀 → 稀有 → 史诗 → 传说 → 神话 → **秘境（Secret）** 七档。 |
| **变异形态** | 普通 → 黄金 → 彩虹 → 暗物质。通过融合机逐级合成，属性乘数 1 / 1.5 / 2.5 / 5，外观材质随之变化（金属金、流动彩虹、紫黑粒子）。 |
| **性格** | 孵化时随机 1 种（勇敢 +ATK −DEF、沉稳 +DEF −SPD 等 8 种），可用道具重随。 |

### 4.2 稀有度数值框架

| 稀有度 | 属性乘数 | 一区蛋概率（示例） | 钻石高级蛋概率（示例） | 全服公告 |
|---|---|---|---|---|
| 普通 | 1.0 | 55% | — | 否 |
| 优秀 | 1.5 | 28% | — | 否 |
| 稀有 | 2.5 | 12% | 45% | 否 |
| 史诗 | 4.5 | 4% | 35% | 否 |
| 传说 | 8 | 0.9% | 15% | 是 |
| 神话 | 15 | 0.099% | 4.95% | 是 |
| 秘境 | 30 | 0.001% | 0.05% | 是（全服 + 特效） |

> 所有涉及 Robux（或用 Robux 可购得的货币）购买的随机物品，**必须在购买前以百分比数值展示每个结果的概率，总和 = 100%**，幸运加成生效时概率需动态更新。这是 Roblox 平台硬性政策（2026-05 再次明确），UI 设计已纳入（见 12.3）。

### 4.3 获取途径

| 途径 | 说明 | 对应目标 |
|---|---|---|
| 孵蛋 | 每个区域有专属蛋池（金币购买），高级蛋用钻石 | 主要产出 |
| 野外捕捉 | PvE 中把野生灵宠打到 20% 血以下，投掷"方块胶囊"，成功率随血量与品质变化 | 探索乐趣 |
| 远征限定 | 仅在 Rogue 深渊等级 ≥ N 掉落的专属灵宠 | Rogue 驱动 |
| 竞技赛季奖励 | 排位达到段位获得限定灵宠 / 皮肤 | PvP 驱动 |
| 融合机 | 5 只同种 → 上一级变异形态（保底 100%）；3 只 + 钻石 → 概率合成 | 收集 & 货币回收 |
| 活动限定 | 节日 / 联动，过期不再复刻（或一年后复刻） | 稀缺与 FOMO |
| 交易（二期） | 玩家间交易，需遵守 Roblox `IsPaidItemTradingAllowed` 策略 | 社交经济 |

### 4.4 培养维度

| 维度 | 上限 | 资源 | 效果 |
|---|---|---|---|
| 等级 | 每进化阶段 30 / 60 / 100 级 | 经验（战斗 / 经验果） | 属性 +5% / 级 |
| 进化 | 3 阶段（幼体 → 成体 → 完全体） | 等级到顶 + 元素精华 | 属性乘数 1 / 1.6 / 2.5；模型体积变大、细节增加；3 阶解锁强化技能 |
| 星级 | 1★ → 6★ | 同种灵宠碎片 | 每星 +20% 属性；6★ 解锁专属光效 |
| 技能等级 | Lv1 → Lv10 | 技能书 | 技能倍率与效果增强 |
| 变异形态 | 4 档 | 融合机 | 属性乘数 & 外观 |
| 饰品（二期） | 2 格 | PvE 掉落 / 远征 | 词条加成（暴击、吸血、冷却…） |

**战力公式（用于显示与匹配）**
`Power = (HP/10 + ATK×2 + DEF×1.5 + SPD×0.5) × 稀有度乘数 × 星级乘数 × 变异乘数 × 进化乘数`

|---|---|---|---|---|
| 焰尾狐 | 火 / 攻击 | 稀有 | 烈焰冲刺：突进并对路径敌人造成 220% 伤害，附加灼烧 | 攻击灼烧目标时暴击率 +15% |

## 5. 战斗系统（全自动）

### 5.1 定位与原则

- **战斗全自动**：灵宠由 AI 自动普攻、自动释放技能，玩家在战斗中**不做任何操作**（只可调速 / 跳过）。
- **决策在战前，爽感在战中**：玩家能影响胜负的只有两类东西——
  1. **局外养成**：灵宠品质 / 等级 / 进化 / 星级 / 变异 / 技能等级、训练师天赋、图鉴加成、轮回乘数；
  2. **局内 Rogue 加成**：遗物三选一、事件取舍、商店、篝火、路线选择。
- **确定性模拟**：给定双方状态 + 随机种子，战斗结果唯一。服务端负责结算，客户端只负责播放。好处：天然反作弊、"跳过"零成本、异步 PvP 绝对公平、可离线批量跑上万场做数值平衡。
- 训练师（玩家 Avatar）负责在 3D 世界探索、触发关卡、经营营地、走 Rogue 地图；战斗开始后退到观战位。

### 5.2 队伍格数路线

| 阶段 | 出战格 | 说明 |
|---|---|---|
| **MVP（P0–P2）** | **1v1** | 单只灵宠对撞。全部数值、遗物、UI 围绕 1v1 打磨 |
| 上线后评估 | 3 格 | 视 1v1 版本数据决定是否开放；建议解锁：通关第 3 区 → 第 2 格，轮回 1 → 第 3 格 |
| 上限 | 5 格 | 轮回 3 → 第 4 格，轮回 6 → 第 5 格；多格时引入前排 / 后排站位与光环类被动 |

数据结构自 P0 起按 5 格设计（`team[1..5]`、技能目标选择支持多目标），UI 与数值先只开放 1 格，避免后期重构。

### 5.3 自动施法 AI

每个技能在配表中带**触发条件**，由策划定义、玩家不可改、**遗物可改**：

| 触发类型 | 示例 |
|---|---|
| 冷却就绪即放 | 攻击型技能默认 |
| HP 阈值 | 潮汐蛙「水泡护盾」：自身 HP < 60% 且冷却就绪 |
| 打断 | 拥有「洞察」被动或对应遗物时，在敌方蓄力条 ≥ 80% 时优先释放技能打断，伤害 +50% |
| 目标状态 | 焰尾狐「烈焰冲刺」：目标已灼烧时优先释放 |
| 开场 | 部分遗物提供"开场立即释放一次技能" |

"什么时候放技能"不由手操决定，而由**灵宠种类 + 遗物构筑**决定，构筑深度得以保留（例：叠加"技能命中减冷却"与"技能命中回血"遗物形成技能循环流）。

### 5.4 战斗流程与时长

1. **战前面板**：双方灵宠、元素克制提示、双方战力、本局遗物 → 点击"开战"（Rogue 中节点预告敌方元素，可先选路）。
2. **战斗**：普攻按 SPD 决定攻击间隔，技能按 5.3 触发；伤害数字弹出、状态图标、敌方蓄力条。
3. **速度**：1× / 2× / 3×（3× 通关第 2 区解锁）；"跳过"直接出结算（服务端已算完）。
4. **时长目标**（1× 观看）：普通 15–30 秒，精英 40 秒，Boss 60–90 秒。
5. **结算**：胜负、剩余 HP、掉落，（Rogue）三选一遗物。

### 5.5 伤害公式（原型期用模拟器校准）

```
攻击间隔    = 1.0 / (SPD / 100)  秒
减伤率      = DEF / (DEF + 40 × 目标等级)              -- 百分比减伤，随等级缩放，避免防御溢出
基础伤害    = ATK × 技能倍率 × (1 − 减伤率)
最终伤害    = 基础伤害 × 元素克制(1.5 / 1 / 0.67) × 暴击(1.5) × 打断加成(1.5，仅满足 5.3 条件) × 随机(0.95–1.05)
```

全部随机数取自战斗种子，保证可复现。

### 5.6 状态效果（首发 8 种）

灼烧（持续伤害）、冰缓（减速）、缠绕（定身 / 跳过普攻）、致盲（命中 −50%）、护盾、回血、攻速提升、易伤（受伤 +25%）。1v1 下状态效果是构筑核心，遗物大量围绕它们联动。

### 5.7 1v1 下的"元素被克"问题

1v1 中被克制意味着约 45% 的双向劣势，必须避免"抽到就输"：

- Rogue 地图节点**预告敌方元素**，玩家可选路规避，或提前在商店备好「元素护符」类遗物；
- 提供「中和」类遗物（被克惩罚减半）与「逆转」类传说遗物（克制关系反转）；
- PvE 关卡固定敌方元素并在入口显示，鼓励培养多元素灵宠（反向推动收集）；
- "战前从后备中选出战灵宠"作为待决策项（第 16 章 #11，对应 `docs/DECISIONS.md` D-12）。

### 5.8 敌人与 Boss

- 普通怪：无技能、纯数值；精英：1 个带蓄力条的技能（给"打断"构筑发挥空间）。
- Boss：3 阶段，每阶段一种机制（狂暴 / 召唤护盾方块需先打碎 / 反伤），阶段切换时体素模型崩裂变形。

## 7. Rogue 远征模式："迷雾远征"

### 7.1 设计目标

- 提供**每局不同**的核心重玩内容，单局 15–25 分钟。
- 通过**遗物构筑**让同一只灵宠打出完全不同的流派。
- 失败也有收获（元进度），并成为增量系统的一环。

### 7.2 单局结构

```
入口（选 1 只出战灵宠，消耗 1 张远征门票；开放多格后按格数扩展）
   │
   ▼
第 1 层「迷雾森林」 12 节点 ─────────────────────────────▶ 层 Boss
   ├─ 战斗 ○   ├─ 精英 ◆   ├─ 事件 ?   ├─ 商店 $   ├─ 篝火 ▲   ├─ 宝箱 ■
   │
   ▼  （通关后选择：撤离带走全部奖励 / 继续深入，奖励 ×1.5 但失败损失 50%）
第 2 层「熔炉回廊」 12 节点 ─────────────────────────────▶ 层 Boss
   │
   ▼
第 3 层「深渊之心」 12 节点 ─────────────────────────────▶ 最终 Boss（随机 1 / 5）
   │
   ▼
结算：远征印记 × 深度系数 × 深渊等级系数 ；遗物图鉴登记 ；限定掉落判定
```

**地图**：Slay the Spire 式分支节点，每层 12 节点 3 条路径，玩家能看到前方 2 步的节点类型，鼓励规划。

### 7.3 节点类型

| 节点 | 内容 |
|---|---|
| 战斗 ○ | 普通战斗，胜利后 3 选 1 遗物（普通 / 稀有权重） |
| 精英 ◆ | 强敌，掉落稀有 / 传说遗物 + 更多远征金币 |
| 事件 ? | 文字 / 场景事件，有取舍（示例见 7.5） |
| 商店 $ | 用远征金币购买遗物、药水、临时技能升级、移除诅咒 |
| 篝火 ▲ | 回复 30% HP **或** 本局永久升级技能 **或** 移除 1 个诅咒遗物 |
| 宝箱 ■ | 必得 1 遗物，10% 概率为"诅咒宝箱"（强遗物 + 负面效果） |
| Boss | 每层固定 1 个 Boss，最终层从 5 个 Boss 中随机 |

### 7.4 遗物系统（首发 80 个，MVP 35 个）

| 品质 | 数量占比 | 示例 |
|---|---|---|
| 普通 | 45% | 「厚实方块」全队 HP +15% ；「磨刀石」ATK +10% |
| 稀有 | 35% | 「余烬之心」火系技能命中后额外叠 1 层灼烧；「回声哨」训练师指令冷却 −40% |
| 传说 | 15% | 「时间沙漏」每场战斗第一个技能不进入冷却；「共生藤」草系回血量 50% 转化为护盾 |
| 诅咒 | 5% | 「贪婪之匣」远征金币 ×2，但每场战斗开始扣 5% HP |

设计原则：**每个元素 / 职业 / 状态效果至少有 3 个以上遗物形成流派**（灼烧流、护盾反伤流、暴击刺客流、召唤流、吸血续航流……）。

### 7.5 事件示例

- **方块祭坛**：献祭本局 25% 最大 HP 换取 1 个传说遗物。
- **迷路的灵宠**：一只野生灵宠愿意同行，本局提供 1 个随机被动光环（不占出战格）；通关后 30% 概率永久获得。
- **神秘商人**：用当前 HP 而不是金币购买遗物。
- **裂缝回响**：预览下层 Boss 并选择 1 个针对性增益。
- **像素熔炉**：把 2 个普通遗物合成 1 个随机稀有遗物。

### 7.6 元进度（永久成长）

- **远征印记**（失败也按深度结算）→ **元天赋树**（3 分支 × 10 节点）：
  - 探险：初始遗物 +1、商店折扣、地图预览 +1 步、每层 1 次重随三选一
  - 生存：初始 HP +%、篝火回复 +%、每局 1 次免死（不可用于周挑战榜）
  - 深渊：解锁新遗物入池、解锁新事件、解锁新 Boss、提升限定掉率
- **遗物图鉴**：收集到的遗物永久登记，每 10 个提供 +1% 全局属性（收集 → 增量）。

### 7.7 深渊等级与周挑战

- **深渊等级 1–20**（Hades 热度式）：每级叠加 1 个负面修饰（敌人 HP +20%、精英翻倍、篝火只回 15%……），奖励系数随之提升；≥ 10 级才能掉落远征限定灵宠。
- **每周种子挑战**：全服同一地图、同一遗物序列、固定标准化灵宠（不吃养成），按通关时间 / 深度排行，前 100 名获得称号与皮肤 → **给高玩公平舞台，也为内容创作者提供话题**。

### 7.8 门票经济

- 每天免费 3 张，营地"远征哨站"额外产出，钻石可买（每日上限 5 张，防止付费无限刷）。

## 8. 增量 / 放置系统

### 8.1 灵宠营地（放置生产）

未出战的灵宠不闲置——分配到营地建筑里工作。

| 建筑 | 产出 | 解锁 | 岗位数（初始 → 满级） |
|---|---|---|---|
| 方块矿场 | 金币 | 初始 | 3 → 10 |
| 经验果园 | 经验果（宠物经验道具） | 玩家 Lv5 | 2 → 8 |
| 孵化研究所 | 蛋碎片、孵化加速 | 玩家 Lv10 | 2 → 6 |
| 远征哨站 | 远征门票 / 少量印记 | 首次远征后 | 1 → 4 |
| 竞技训练场 | 竞技勋章（少量） | 解锁 PvP 后 | 1 → 3 |

- **单只产量** = `Power^0.6 × 元素匹配加成(1.25) × 变异乘数 × 建筑等级乘数`
- **建筑升级**：经典增量曲线，产量 ×1.15 / 级，费用 ×1.20 / 级；里程碑等级（10/25/50）解锁自动化（自动收取 → 自动孵化 → 自动融合）。
- **离线收益**：上限 8 小时（VIP 12 小时），回归时弹出"离线收益"大数字面板，可看 15 秒广告 —— *注：Roblox 目前无内嵌广告 SDK，此处改为"用钻石翻倍"*。

### 8.2 轮回（Prestige）

| 项目 | 设计 |
|---|---|
| 首次条件 | 通关第 3 区 Boss |
| 之后条件 | 任意时间，但轮回点收益取决于本轮最远进度与累计金币 |
| **重置** | 区域进度、金币、营地建筑等级、训练师等级 |
| **保留** | 全部灵宠及其等级 / 星级 / 变异、图鉴、遗物图鉴、元天赋、钻石、皮肤 |
| 轮回点公式 | `floor( 最远关卡数^1.2 / 20 + sqrt(本轮累计金币 / 1e6) )` |
| 轮回点效果 | 每点：全部产出 +8%、灵宠属性 +3% |
| 里程碑 | 轮回 1：第 4 区 + 自动孵化；轮回 3：第 5 区 + 彩虹融合；轮回 5：第 6 区 + 暗物质融合 + 秘境蛋池；轮回 10：轮回天赋树第二页 |

第 N 次轮回的目标：让前几区被"秒推"（乘数碾压）、在新区域重新遇到瓶颈 —— 经典的增量节奏。

### 8.3 大数字呈现

所有货币与伤害使用 K / M / B / T / Qa / Qi… 后缀，伤害数字弹出使用体素字体 + 暴击放大。

## 10. 社交、经济与运营

### 10.1 PvP 竞技

| 模式 | 描述 | 上线阶段 |
|---|---|---|
| **异步竞技场** | 挑战其他玩家设置的防守灵宠 / 阵容，双方全自动、服务端确定性结算；随时可玩、无延迟、无需对手在线 | **MVP** |

### 10.2 社交

- 公会（二期）：公会 Boss、公会商店、公会科技。
- 交易（二期，需评估）：玩家间灵宠交易。Adopt Me 证明交易是极强留存引擎，但带来骗局客服、刷物漏洞风险；上线后视社区规模决定，且必须使用 `PolicyService.IsPaidItemTradingAllowed` 做合规分流。

## 12. 美术 / 音频 / UI 规范

### 12.1 美术方向

- **风格关键词**：明亮、饱和、圆润体素（MagicaVoxel 风）、"可爱但能打"。
- **灵宠模型**：**起始（幼体）约 32 格高**（32³ 体素空间），成体约 40 格，完全体约 48 格——进化以"增加体积 + 配件 + 发光部件"表现，而非简单放大；贪婪网格合并后 ≤ 3,000 三角面 / 只，≤ 2 个材质。
- **比例**：1 体素 ≈ 0.1 stud，幼体约 3.2 stud 高（略低于 5 stud 的玩家 Avatar）；场景方块使用更粗的 1 stud 单元（角色精细、地形粗粝是体素游戏的常见做法）。
- **变异材质**：黄金 = 金属高光；彩虹 = 逐面色相循环（着色 / 贴图动画）；暗物质 = 紫黑 + 粒子拖尾。
- **场景**：体素地形分块（Streaming 加载），每区一套主色板；Boss 场景有独立光照氛围。
- **特效**：技能特效用体素粒子（方块碎片）而不是常规粒子贴图，保持风格一致；伤害数字用像素字体。
- **动画**：灵宠 6 个基础动画（待机 / 跑 / 攻击 / 技能 / 受击 / 倒下）+ 1 个进化演出。

### 12.2 制作管线

MagicaVoxel 建模 → 导出 OBJ → Blender 合并面（贪婪网格 / Decimate）+ 贴图烘焙 → Roblox MeshPart 导入 → 骨骼绑定与动画在 Blender 完成后导入（或使用 Roblox 内置 Rig 编辑器）。**一只 32 格灵宠的美术产能目标：2 人天（含 4 变异材质与 6 个基础动画）**。

### 12.3 关键界面清单

主 HUD（金币 / 钻石 / 战力 / 任务追踪 / 战斗速度与跳过按钮）、灵宠背包、灵宠详情（培养）、孵蛋界面（**含概率明细弹窗"Details"**）、融合机、营地、远征地图、遗物三选一、远征结算、竞技场、图鉴、商店、任务 / 通行证、排行榜、全服公告条、设置。

**移动端规范**：所有可点击元素 ≥ 44pt；速度 / 跳过按钮位于右下拇指区；重要面板支持单手滑动关闭。

### 12.4 音频

轻快的 chiptune × 管弦混合 BGM，每区一首 + Boss 一首 + 远征三层各一首；技能音效强调"方块碎裂"质感；传说以上孵化有专属音效与全服公告音。

## 14. 技术方案

| 领域 | 方案 |
|---|---|
| 引擎 / 语言 | Roblox Studio + Luau；`Rojo` + VS Code + Git 做源码管理；`Wally` 管包；`StyLua` / `Selene` 规范 |
| 架构 | **服务端权威**：伤害、掉落、货币、孵蛋全部在服务端结算；客户端只做输入与表现；RemoteEvent 限频 + 参数校验 |
| 数据存储 | `ProfileStore`（会话锁防重复登录刷物）+ DataStore 版本化；存档结构带 `schemaVersion` 支持迁移；每日快照备份；回档工具 |
| 战斗模拟 | **确定性模拟**：服务端以种子运行完整战斗，产出事件序列（普攻 / 技能 / 状态 / 死亡），客户端按序列播放动画；"跳过"直接取结算。模拟器为纯 Luau 模块（不依赖 Roblox API），可在 Lune CLI 中批量跑万场做平衡与回归测试 |
| 实例化玩法 | Rogue 与 PvP 在主服务器内使用**远距离隔离区域 + StreamingEnabled**（省去传送等待）；玩家数 > 阈值时升级为 `TeleportService` 预留服务器 |
| 匹配 | `MemoryStoreService` 队列（实时 PvP 阶段） |
| 跨服通信 | `MessagingService`：全服稀有公告、世界 Boss 状态 |
| 远程配置 / 活动 | DataStore 配置表 + Open Cloud API 后台写入，无需发版即可开活动、改概率（改概率需同步更新披露 UI） |
| 合规 | `PolicyService:GetPolicyInfoForPlayerAsync` 处理 `ArePaidRandomItemsRestricted` / `IsPaidItemTradingAllowed` |
| 分析 | Roblox Analytics（留存 / 漏斗 / 经济事件）+ 自定义事件：FTUE 每步、孵蛋结果、远征每层与遗物选择、轮回、付费 |
| 性能预算 | 移动端 ≥ 30 fps（目标 60）；单屏 ≤ 300k 三角面；灵宠 ≤ 3,000 面（32 格贪婪网格后）；主城同屏灵宠 ≤ 20；单场 1v1 模拟 ≤ 2 ms（服务端一次性算完） |
| 反作弊 | 服务端权威 + 数值合理性检查（单位时间金币增量上限）+ 异常账号标记 + Roblox 客户端保护（Hyperion） |
| 本地化 | Roblox 本地化表，所有 UI 文本走 Key；数字缩写按语言适配 |

### 15.2 风险与应对

| 风险 | 等级 | 应对 |
|---|---|---|
| 系统太多，年轻玩家上手门槛高 | 高 | 分层解锁（3.3 节奏表）；每个系统一句话教学；P1 阶段用 50 人测试验证 FTUE |
| 全自动战斗观感枯燥、玩家觉得"没在玩" | 高 | 提高战前决策密度（每 1–2 场一次三选一、节点预告、路线取舍）；技能演出 + 伤害数字 + Boss 阶段演出；速度控制与跳过；P0 用"还想再来一局"指标验证 |
| 1v1 被元素克制导致挫败 | 中 | 5.7 节四项缓解；克制倍率上限 1.5；首颗蛋必出不同元素 |
| Roblox 宠物赛道竞争激烈、买量成本上升 | 中 | 差异化在"战斗 + Rogue"；靠点赞率与时长进入推荐；YouTuber 试玩计划；Discord 社区预热 |
| 体素模型面数失控导致移动端卡顿 | 中 | 管线内置面数检查脚本；LOD；同屏灵宠上限 |
| 存档丢失 / 回档 → 差评 | 高 | ProfileStore + 快照备份 + 客服补偿工具，Alpha 期专项测试 |
| 刷物 / 外挂破坏经济 | 中 | 服务端权威；交易延后；异常检测 |
| 付费随机物品合规 | 中 | 概率披露 UI 为 MVP 必做项，法务 / 政策 checklist 上线前复核 |
| 内容消耗快于产出 | 高 | Rogue 与增量本身抗消耗；美术管线目标 2 人天 / 灵宠；提前储备 2 周更新内容 |
| 范围蔓延 | 高 | 严格按 13.1 MVP 表执行；新想法进 backlog 排期 |
